# ATS-Friendly Layout Guidelines

## Core Principle: Simple & Scannable

**AI makes layout decisions based on content, not hardcoded rules.**

## Header Format
```
FULL NAME
phone | email | linkedin | location
```

## Skills Section Format
```
TECHNICAL SKILLS

Category: item1, item2, item3
Category: item1, item2
```
- One category per line
- Comma-separated
- No bullets, no tables

## Experience Format
```
EXPERIENCE

Job Title | Company | Dates
• Bullet with X-Y-Z formula
• Bullet with metrics
```

## ATS-Friendly Rules (STRICT)

✅ **Must Have:**
- Single-column layout
- Standard fonts (Helvetica, Arial, Calibri)
- Simple bullets (• or -)
- Clear section headers
- Black text on white

❌ **Never Use:**
- Multi-column layouts
- Tables for experience/skills
- Images or graphics
- Text boxes
- Fancy fonts
- Headers/footers with critical info

## Typography Decisions (AI-Driven)

**AI decides based on word count:**
```
< 500 words: 10pt body, 0.75in margins
500-600 words: 9pt body, 0.5in margins
> 600 words: FAIL, request content reduction
```

## 1-Page Strategies

If approaching 2 pages:
1. Reduce font (10pt → 9pt → 8.5pt min)
2. Tighten margins (0.75in → 0.5in)
3. Reduce spacing (1.15 → 1.0)
4. Trim older roles (5+ years ago: 2 bullets max)

**Target: Exactly 1 page for < 12 years experience**

**Pure AI decisions - no static formatting.**
